# Где ASR ломается на казахском

Аудит качества распознавания казахской речи: не «какой WER», а **из чего этот WER состоит**
и насколько ему вообще можно верить на агглютинативном языке с собственной графикой.

## Запуск

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
pip install --index-url https://download.pytorch.org/whl/cpu torch torchcodec

python src/prepare_data.py --minutes 12
python src/transcribe.py --model large-v3 --lang kk --device auto
python src/transcribe.py --model small    --lang kk --device auto
python src/transcribe.py --model large-v3 --lang none --device auto   # без подсказки языка
python src/evaluate.py --hyp results/hyp_large-v3_kk.tsv
```

По умолчанию проект использует локальный кэш в `.hf_cache`, чтобы не зависеть от
`~/.cache/huggingface` и не ломаться в ограниченных средах вроде VS Code / sandboxes.
На macOS и CPU лучше работать через `--device cpu` и `--compute_type int8`; на GPU —
`--device cuda --compute_type int8_float16`.

В Colab (T4, бесплатный тариф) прогон 12 минут аудио на `large-v3` в `int8_float16`
занимает порядка 5–8 минут.

## Что считаем и зачем

| Метрика | Что делает | Что показывает разница |
|---|---|---|
| `WER_raw` | без нормализации | — |
| `WER_norm` | регистр, пунктуация, дефисы | `raw − norm` = ошибки **метрики**, а не модели |
| `WER_fold` | + ә/ө/ұ/ү/і/ң/қ/ғ → русские аналоги | `norm − fold` = цена **казахской графики** |
| `WER_stem` | + срезание аффиксов | `norm − stem` = цена **морфологии** |
| `CER_norm` | посимвольно | устойчивее WER на агглютинативном языке |

Главный тезис работы: на казахском один неверный аффикс делает всё слово заменой,
поэтому WER систематически завышает деградацию по сравнению с английским.
`WER_stem` и `CER` показывают, сколько смысла модель на самом деле удержала.

## Типология ошибок

Классификатор в `src/evaluate.py::classify` раскладывает каждую замену на:

- спецбуквы (ә/ө/ұ/ү/і/ң/қ/ғ схлопнулись в а/о/у/и/н/к/г)
- аффикс — корень совпал, окончание нет
- спецбуквы + аффикс
- близкая форма — фонетически похоже
- уход в русскую графику
- полная замена слова
- пропуск / вставка слова

Плюс отдельно: матрица подмен символов, кандидаты в галлюцинации (гипотеза
аномально длиннее эталона) и распределение автоопределённого языка.

- **Важно:** FLEURS — студийная читаная речь. Это верхняя граница качества.
  Отдельно прогнать 3–5 минут спонтанной речи и показать разрыв.

## 2. Таблица ошибок

`results/table_*.tsv` — что сказали / что распозналось / поуттерансный WER.
В отчёт — 15–20 самых показательных строк, не всё.

## 3. Разбор по типам

Таблица долей + вывод: какие типы доминируют и почему именно они.

## 4. Насколько цифрам можно верить

- Разброс между четырьмя WER.

- Что метрика штрафует несправедливо, а что пропускает.
